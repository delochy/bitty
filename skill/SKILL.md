# AI Side Quest

AI가 작업하는 동안 기다리는 사람이 심심하지 않게, 그 자리에서 할 만한 작은 퀘스트를
추천하는 도구다. 사용자를 자리에서 떠나보내는 게 목적이 아니다 — "자리 비우기",
"다녀오세요" 같은 표현은 쓰지 않는다.

평소에는 스킬이 할 일이 거의 없다. 작업이 30초 넘게 걸리면 화면 오른쪽 아래 마스코트
위젯이 알아서 뜨고, 끝나면 삐빅 소리와 함께 사라진다.

## 원칙

- **시간을 먼저 묻지 않는다.** 추천은 위젯이 알아서 보여준다.
- **소요시간을 예측해서 말하지 않는다.** "이 작업은 10분 걸려요" 같은 표현 금지.
- 사용자가 고른 시간은 작업 예상시간이 아니라 **퀘스트로 놀고 싶은 시간**이다. 강제 타이머도
  아니다 — 작업이 먼저 끝나면 그걸로 끝.
- 퀘스트는 1~3개만 보여주고 꾸미거나 늘리지 않는다. 쉬는 것도 정상적인 선택지다.

## 도구

- `sidequest_report_estimate({ sessionId, size })` — 도구를 쓰는 작업을 시작할 때 규모를
  `SHORT`(작은 수정·간단한 조사) / `MEDIUM`(여러 파일 수정·테스트) / `LONG`(빌드·대규모 작업)
  중 하나로 보고한다. 위젯이 퀘스트 길이를 고르는 데만 쓴다. sessionId는 훅 지시문에 적힌
  값을 그대로 쓴다.
- `sidequest_select_time_budget({ sessionId, minutes })` — 사용자가 **먼저** "10분",
  "끝날 때까지"처럼 말했을 때만 호출하고, 돌려받은 퀘스트를 그대로 보여준다.
- `sidequest_get_state()` — "작업 끝났어?", "지금 상태 어때?"에 답할 때.
- `sidequest_list_quests({ bucket })` — 퀘스트 목록이 궁금하다고 할 때.
- `sidequest_record_choice({ sessionId, bucket, questId })` — 채팅에서 퀘스트를 골랐다고
  말하면 기록한다.

## 톤

가볍고 짧게. 잔소리하지 않는다. 퀘스트를 안 해도 괜찮다는 느낌을 유지한다.
