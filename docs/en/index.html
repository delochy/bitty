A mascot for the time
your AI is working

When a Claude Code or Codex task runs longer than 30 seconds, Idle Buddy pops a small mascot into the bottom-right corner of your screen and suggests something to do. When the task finishes, it chimes and fades away.

Get it on GitHub Latest release

Things to do while you wait

  • 10 mini games — Block Stack, Sudoku, 2048, Minesweeper, Snake, Whack-a-mole, Tic-tac-toe, Memory Match, Reaction Test, Typing
  • Fun — 69 dev jokes and 50 riddles, with no repeats until you have seen them all
  • Chill — a campfire and an ocean view with optional ambient sound, a breathing exercise, stretching
  • Chores — shopping list, tidy your Desktop or Downloads, free up disk space. Tapping one opens the right app.

Everything runs inside the widget window. No browser tab to get lost in.

The waiting adds up

  • Grow your buddy — time waited and quests picked earn XP. Levels unlock ribbons, glasses, hats, crowns and colors.
  • Today's wait report — how long you waited on AI, how many tasks ran over 30 seconds, tokens burned across Claude and Codex, and what you did meanwhile. Saves as a 1080×1350 image.
  • Pick up where you left off — if the widget closes mid-game, it reopens that game next time.
  • Claude and Codex together — one window shows which tool is working, tells you which finished, and uses a different sound for each.

The screenshots show the Korean UI. The widget switches to English automatically when your Mac is not set to Korean, and the globe button cycles languages.

How it works

Claude Code / Codex ──(hooks)──▶ data/state.json ◀──(polled every 2s)── mascot widget
                                                            │
                        local page http://127.0.0.1:4318/quest (games & quests)

A hook records when a task starts. If it is still running after 30 seconds, the mascot appears — but only once you stop typing, and it never steals focus. Suggestions adapt to the task size: Claude reports a rough size over MCP, and they get longer if the task drags on. It never claims "this will take N minutes".

Install

You need macOS and Node.js 18 or later, plus Claude Code or Codex. Rust is optional — without it the installer downloads a prebuilt app from Releases.

git clone https://github.com/delochy/idle-buddy.git
cd idle-buddy
sh install.sh

The installer adds hooks and registers an MCP server for Claude Code and Codex, then installs the widget into ~/Applications and launches it. Every config file it touches is backed up as .bak-<timestamp> first.

Update

git pull && sh install.sh

Uninstall

node uninstall.js

Removes the hooks, the MCP registration, the login item and the widget app. Your repo folder and data/ history are left alone.

Privacy

No server and no account. Everything stays in the local data/ folder: task start and end times, the working folder, the first 200 characters of each prompt, and the quests you picked.

Token counts in the report are read from the usage numbers that Claude Code (~/.claude/projects) and Codex (~/.codex/sessions) already log. Typing detection only checks when a key was last pressed — it cannot see which key, so it needs no Input Monitoring permission.

Known limitations

  • The widget is macOS-only. Hooks and the quest page run elsewhere, but the floating window does not.
  • Codex silently skips new hooks until you trust them once.
  • The app is not signed or notarized by Apple.

Frequently asked questions

What is Idle Buddy?

A macOS widget that pops a small mascot into the bottom-right corner of your screen when a Claude Code or Codex task runs longer than 30 seconds. It suggests a mini game, a joke, an ambient rest mode or a short chore while you wait, then chimes and fades away when the task finishes. It is free and MIT licensed.

Does it work on Windows or Linux?

Not yet. The hooks and the quest page run anywhere, but the floating mascot window is macOS-only. Both Apple Silicon and Intel are supported.

Can I use it with only Codex, without Claude Code?

Yes. Either one is enough. If you run both, a single window shows which tool is working and which one finished, with a different sound for each.

How do I install it?

You need macOS and Node.js 18 or later. Clone the repository and run install.sh. The installer adds hooks and registers an MCP server for Claude Code and Codex, then installs the widget into ~/Applications. Rust is optional; without it the installer downloads a prebuilt app from Releases.

Is any data sent anywhere?

No. There is no server and no account. Everything stays in the local data/ folder: task start and end times, the working folder, the first 200 characters of each prompt, and the quests you picked. Typing detection only reads when a key was last pressed, never which key, so no Input Monitoring permission is needed.

The mascot never appears.

Restart any Claude Code or Codex session that was already running when you installed. Codex also requires you to trust new hooks once: run codex in a terminal and choose Trust all and continue on the "Hooks need review" screen, otherwise the hooks are silently skipped.
